# 🌟 为什么创建这个项目？

现在很多背单词软件不断增加越来越多功能：

-   复杂学习计划
-   多种学习模式
-   成就系统
-   强制复习流程
-   大量设置和任务

但是背单词本身已经足够困难。

学习工具不应该成为用户需要额外学习的新系统。

所以我创建了 **英语词汇记忆**。

它坚持一个简单理念：

> **背单词软件应该帮助用户记住单词，而不是管理用户的学习流程。**

------------------------------------------------------------------------

# 🎯 设计理念

## 极简主义：回归背单词本质

背单词的目标其实很简单：

> **记住单词。**

因此，本项目刻意减少不必要的复杂设计。

没有大量让人迷失的功能。

只保留最核心的学习流程：

1.  学习单词
2.  验证记忆

------------------------------------------------------------------------

# 📖 背诵页面

提供一个专注的学习环境。

你可以：

-   查看单词
-   学习释义
-   阅读例句
-   听取发音

没有复杂流程。

没有额外干扰。

只专注学习。

------------------------------------------------------------------------

# ✍️ 默写页面

认识一个单词，不代表真正掌握。

很多时候，我们只是：

"看起来认识"。

但真正掌握一个单词，需要能够主动回忆并正确拼写。

默写页面负责最终验证：

> **你是否真的能够写出这个单词？**

只有通过默写验证，单词才会被认为真正掌握。

------------------------------------------------------------------------

# 🧠 把判断权交还给学习者

很多背单词软件会替用户决定：

-   什么时候算学会
-   一个单词需要复习多少次
-   什么时候可以标记为掌握

但是学习是个人化的。

每个人的记忆能力、学习速度和学习习惯都不同。

本项目采用另一种方式：

> **学习者决定自己是否理解，系统负责验证是否真正记住。**

学习过程中保持自由。

最终结果通过默写检验。

# 🔄 推荐学习流程

## 1. 先回忆

看到英文单词后，尝试回忆它的含义。

不要立即查看答案。

------------------------------------------------------------------------

## 2. 理解上下文

查看：

-   中文释义
-   英文例句
-   发音

真正理解单词使用方式。

------------------------------------------------------------------------

## 3. 默写验证

通过主动回忆检查：

-   是否记住含义
-   是否能够正确拼写

------------------------------------------------------------------------

## 4. 回顾薄弱词汇

重新练习还没有掌握的单词。
