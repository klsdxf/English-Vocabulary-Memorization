六级词汇 V2.0 · Windows 桌面版

解压后双击“六级词汇.exe”；保留同目录配置文件。运行需要 Windows 10/11 与 .NET Framework 4.7.2 以上，不需要 Python、Excel、Node 或开发 SDK。

升级：先关闭旧软件。默认学习档案继续使用本机 CET6Word 目录。第一次启动新版自动生成并验证升级前完整备份，再合并词库，保留旧记录。不要删除原数据目录。

背诵：默认每页 20 词，点击单词先看释义，再看首条例句，第三次收起。查看更多例句可以展开其余句子，每句都能独立朗读。可改每页 10/20/30/50，输入页码跳转；非输入框焦点时左右方向键翻页。滚轮只滚动当前页。固定/随机顺序、页码和页内位置会保存。

搜索：背诵页右侧实时搜索完整正式原词书，仅支持英文片段。搜索只供查看与发音，不记为学习，不管理收藏/熟词。关闭后继续原页。

单词本：原词书、收藏词本、已记诵词本三个入口。收藏词本里保留默认收藏和自定义词本，可多归属。已记诵以当前熟词或最后一次可靠默写正确为准；它与错词本连续答对阈值分别计算。

默写：选择最近主动学习的词，或指定范围随机抽取；支持中文提示、听音提示。错误保留在错词记录中，默认连续答对两次移出待复习，全部历史保留。

发音：只播放美式英语、正常语速。自动朗读默认关闭，在“更多 → 设置与数据”可开启。未配置在线服务时使用 Windows 美音；本机需有英语（美国）语音。可选 Azure 服务需自己的区域与密钥。

导入：更多 → 词库管理，支持 CSV/XLSX；每次新建独立词库，不覆盖原词书。CSV 模板在 data 目录。

备份：更多 → 设置与数据，导出/恢复完整 .cet6backup；学习、收藏、默写、错词、词库和位置均包含，不含语音密钥与缓存。

回退：关闭软件后双击“回退到V1.7.cmd”，恢复最近升级前档案并保存新版安全副本，然后启动随包提供的 V1.7。回退后使用 rollback/V1.7 中的旧程序；再次打开主程序会重新升级。完整说明见 docs/V2.0升级与回退.md。

词库：2955 正式词，以有公开数据许可的 OpenEtymology CET6 为主体，美音主要来自 CMUdict。47 个未匹配旧词在升级档案中另行保留，不计入正式词数。代码 MIT；新增词书 CC BY-SA 4.0，许可与检查局限详见 docs/V2.0词库质量报告.md。
