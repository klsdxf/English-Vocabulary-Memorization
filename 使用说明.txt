六级词汇 Windows V1.7 实现版

解压后双击“六级词汇.exe”。保留同目录的 .exe.config 文件。
适用 Windows 10/11，需要 .NET Framework 4.7.2 或更高版本，通常已预装。
不需要 Python、Node、Excel、SDK、账号或服务器。

背诵：点英文一次看释义，第二次看例句，第三次收起。
发音与例句朗读是独立按钮。熟词移出待背，在“更多”里可恢复。
☆/★ 一键收藏。单词本页面支持新建与整理，可按 Ctrl 多选。
排序与学习位置自动保存，重开可继续。

默写：最近 X 个只计算主动展开的单词；也可随机取整个当前词库、
已学习词或词本。支持中文和听音提示。输入后点击提交或按 Enter。
错词可选重练；默认连续答对两次移出待复习，历史记录仍保留。

词库：内置 348 个原创备考精选词，每词有释义和例句；不是官方完整
六级大纲。可在“更多 → 词库管理”导入 CSV/XLSX，模板在 data 文件夹。

语音：默认未配置在线服务时使用 Windows 美式英语语音，缺失时明确
提示。可在设置里配置自己的 Azure Speech 区域和密钥，可能产生费用。
在线失败自动回退本地；语音有缓存。自动朗读默认关闭。

备份：设置页面导出/恢复 .cet6backup 完整学习档案。恢复会覆盖当前
数据并先保留安全副本。备份不含在线密钥和可重建的音频缓存。
默认数据在 %LOCALAPPDATA%\CET6Word，移动程序不会删除学习档案。

更多说明见 README.md；验收、架构和授权说明在 docs 文件夹。
