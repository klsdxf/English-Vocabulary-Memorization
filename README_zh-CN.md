## 让每次背词，都有下一步

看到一个单词觉得眼熟，和能想起它的意思、准确写出它的拼写，是不同的练习目标。

**English Vocabulary Memorization**（源码名称 **CET6Word**）把这些步骤串进一个桌面学习流程：先回忆，再展开释义和例句；听过发音后，用中译英或听音默写检验自己；答错的词自动留下，方便下一次集中练习。

词库、单词本和学习记录保存在本机。日常背诵无需账号或服务器；本地发音使用 Windows 已安装的美式英语语音。

## 你可以用它做什么

| 功能 | 带来的体验 |
| --- | --- |
| 🧭 分页与英文搜索 | 默认每页 20 词，可跳页、按方向键翻页；右侧面板实时搜索完整原词书，仅供查看与发音。 |
| 📚 三个单词本入口 | 原词书、收藏词本、已记诵词本；已记诵按当前熟词或最后一次可靠的默写正确动态更新。 |
| 📖 逐级展开背词 | 默认只显示英文；点击正文看中文，再点击看例句，第三次收起，给主动回忆留出空间。 |
| 🔊 单词与例句朗读 | 两个独立播放入口，也可开启主动展开时自动朗读。 |
| ✍️ 两种默写模式 | 根据中文释义或发音输入英文，提交后立即获得判分反馈。 |
| 🎯 错词集中复习 | 重练本轮错词，或回到历史错词列表；默认连续答对两次移出待复习，阈值可调。 |
| ⭐ 收藏与多单词本 | 一键收藏，也能按主题或学习目标创建多个词本。 |
| ✅ 熟词管理 | 已掌握的词即时移出待背列表，需要时可以恢复。 |
| 🔀 排序与位置恢复 | 支持固定、随机顺序，关闭重开后继续此前的排序和阅读位置。 |
| 📥 自定义词库 | 导入 CSV/XLSX，提前预览有效词、重复词、无效行和缺失例句。 |
| 💾 保存与迁移 | 自动保存学习记录，继续未完成的默写，通过完整备份迁移到另一台电脑。 |

### 从回忆到复习，节奏由你决定

1. **先想一想。** 从只显示英文的列表开始，试着回忆含义。
2. **再展开。** 查看释义与例句，按需听单词或例句发音。
3. **动手写。** 从最近学过的词、随机抽取的词或指定单词本中开始默写。
4. **回到错词。** 集中练习还没写对的词，查看连续答对次数。

“最近学习”只记录主动展开释义或例句的词。滚动列表、收藏、播放发音和全局显示中文，不会被算作主动学习。

## 快速开始

### 直接运行桌面程序

**运行环境：** Windows 10/11、.NET Framework 4.7.2 或更高版本。使用本地发音时，若系统没有可用美音，请先在 Windows 中安装 **英语（美国）** 语音。

1. 使用随本版交付的 **CET6Word-V2.0-Windows.zip** 运行包；源码包需要先构建。
2. 将 ZIP 完整解压到一个文件夹。
3. 双击 **`六级词汇.exe`**，将 `六级词汇.exe.config` 保留在同一目录。

运行现有程序无需安装 Python、Node.js、Microsoft Excel 或 .NET SDK。当前软件界面为简体中文。

### 第一次使用

- 点击单词正文，依次展开中文释义和例句。
- 点击 **发音** 听单词，点击 **朗读例句** 听句子。
- 用 **☆ / ★** 管理收藏，用 **熟词** 标记已经掌握的词。
- 进入 **默写**，设置词汇范围、题数，以及中文提示或听音提示。
- 在 **更多** 中找到已掌握词汇、错词记录、词库管理和设置。

自动朗读默认关闭。默写判分忽略大小写和首尾空白，但要求拼写准确，不接受近似拼写或词形替代。

## 把你的词库带进来

内置 **2955 个去重的正式六级词条**，包含词性、美式音标、中文释义与双语例句，以许可允许使用的 OpenEtymology CET6 词书为主体。并非官方完整考试大纲。升级时另保留 47 个未匹配旧词及其记录，不用这些旧词凑正式词数。

想背自己的资料？打开 **更多 → 词库管理 → 导入 CSV / XLSX**。

```csv
word,meaning,example,example_translation
adapt,适应,We adapt to new situations.,我们适应新的情况。
```

| 列名 | 是否必填 | 内容 |
| --- | --- | --- |
| `word` | 是 | 英文单词 |
| `meaning` | 是 | 中文释义 |
| `example` | 否 | 英文例句 |
| `example_translation` | 否 | 例句的中文翻译 |

也支持 `单词`、`释义`、`例句`、`例句翻译` 等中文表头。

- **CSV 编码：** UTF-8（含 BOM）或 GB18030。
- **XLSX：** 读取第一张工作表，无需安装 Excel；旧 `.xls` 请先另存为 `.xlsx` 或 `.csv`。
- **重复处理：** 忽略大小写去重，保留第一条有效词条。
- **独立学习记录：** 每次导入建立新词库，不同词库中的相同拼写分别保存进度。
- **容量限制：** 单个导入文件最大 50 MB，全部词库合计最多 10 万词条。

可以从 [CSV 导入模板](data/词库导入模板.csv) 开始，也可查看[内置精选词库 CSV](data/六级原词书.csv)。请导入你有权使用的资料；数据来源见[词库与授权说明](docs/词库与授权说明.md)。

## 发音、离线使用与可选在线语音

单词和例句均使用 **美式英语、正常语速**。未配置在线服务时，程序使用 Windows `en-US` 本地语音，并缓存生成的音频供后续使用。

如果你已有 Azure Speech 资源，可在 **更多 → 设置与数据** 填入自己的 **服务区域与密钥**。已实现的适配器使用 `en-US-JennyNeural`，成功后缓存在线音频；在线请求失败时回退 Windows 本地语音。

在线语音需要有效凭据，可能产生供应商费用。仓库验收报告记录了适配器与回退路径的测试，没有声称已用真实 Azure 账号验证云端服务。若本机缺少美式英语语音，需安装后才能正常使用本地朗读。

## 学习档案，跟着你走

默认数据目录为 **`%LOCALAPPDATA%\CET6Word`**。学习档案与程序文件分开保存，移动或替换程序文件夹不会删除学习记录。

通过 **更多 → 设置与数据** 导出或恢复 **`.cet6backup`** 完整备份。

- **备份包含：** 导入词库、排序与位置、学习记录、熟词、单词本、默写轮次与作答、错词历史和偏好设置。
- **备份不含：** 可以重新生成的语音缓存和在线服务密钥。换电脑后需重新配置密钥。
- **恢复方式：** 验证备份后覆盖当前档案，同时保留恢复前的副本。

程序也维护上一份已保存档案用于故障恢复，并阻止同一数据目录被多个实例同时写入。需要独立副本或换电脑时，建议定期导出完整备份。

Azure 密钥由 Windows DPAPI 按当前 Windows 用户加密保存。在线朗读只发送本次请求播放的英文文本，不上传完整学习档案。

## 开发与构建

项目使用 **C# + WPF + .NET Framework**，通过 `System.Speech` 实现本地发音，以 JSON 保存档案，通过 ZIP/XML 读取 XLSX。构建脚本使用已安装 .NET SDK 提供的 Roslyn 编译器。

重新构建需要 Windows 开发环境、**.NET SDK**，以及 `build.ps1` 引用的 **.NET Framework/WPF 程序集**。在 PowerShell 中进入项目根目录后运行：

```powershell
git clone https://github.com/klsdxf/English-Vocabulary-Memorization.git
cd English-Vocabulary-Memorization

# 构建桌面程序
.\build.ps1

# 运行项目自动化测试
.\build.ps1 -Test

# 构建并将便携包、源码包输出到指定目录
.\package.ps1 -Destination .\dist
```

使用独立的学习或测试档案目录：

```powershell
& '.\六级词汇.exe' --data-dir 'C:\CET6Word-Profile'
```

| 位置 | 职责 |
| --- | --- |
| `src/Core.cs` | 学习状态、单词本、默写与错词复习规则 |
| `src/UI.cs` / `src/MainWindow.xaml` | WPF 界面与用户交互 |
| `src/Storage.cs` | 持久化、备份验证、语音密钥加密存储 |
| `src/Imports.cs` | CSV/XLSX 词库导入 |
| `src/Speech.cs` | Windows 语音、可选 Azure 适配器与音频缓存 |
| `data/` | 原创精选词库与导入模板 |
| `tests/` | 学习、存储、导入、语音与界面测试 |
| `docs/` | 架构说明、验收证据与数据授权 |
