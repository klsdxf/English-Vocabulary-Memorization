# 六级词汇 V1.7 架构与开发计划

范围以附件中的已确认条款为基线。附件中的执行建议作为参考，不构成新增需求。第一阶段交付可离线使用的 Windows 桌面程序、源码、词库说明及验收记录。

## 技术架构

- Windows 原生 WPF 界面，目标 .NET Framework 4.7.2，兼容 Windows 10/11。随系统提供运行时，不需要浏览器、服务器或账号。
- Core：词库与进度模型、逐级展开策略、固定/随机序列、主动学习、词本、多对多关系、默写与错词状态。
- Storage：版本化 JSON 档案、原子替换、前一版本安全副本、单进程文件锁、备份验证和恢复。SQLite 是原文建议而非硬性要求；本版避免数据库驱动，存储接口与业务分离，后续可替换。
- Imports：UTF-8/GB18030 CSV 与 XLSX（直接读取 Open XML，无需安装 Excel）。导入预览验证后创建独立词库。
- Speech：美式英语、固定语速；可配置 Azure Speech 官方接口，在线音频缓存，失败回退 Windows en-US 语音。密钥用 Windows DPAPI 加密，备份不含密钥。
- UI：顶部保留背诵、默写、单词本、更多四个入口。背诵列表使用虚拟化，低频管理独立呈现。界面与业务逻辑分离。

## 临时工程默认值 未视为用户已确认

1. 正文点击循环为隐藏 → 释义 → 例句 → 隐藏。开启全局翻译时为释义 → 例句 → 释义；开关不清除逐词展开状态。
2. 默认展示一条例句，数据结构保留多条例句；中文释义完整显示。
3. 最近学习按最后一次主动展开时间降序、按词条去重；不足数量时先提示并按实际可用数量开始。空输入阻止提交；答案忽略大小写和首尾空白，不接受近似拼写或词形替代。
4. 随机排序持久保存排列；排序切换保持当前词作为锚点。不同词库、不同排序各自保存位置。
5. “全部词汇”和词本抽样暂包含熟词，词本允许保留熟词。该选择集中在业务策略中，便于修改。
6. 再次点击收藏取消默认收藏。自定义词本删除有确认提示；不删除原始词条。跨词库同拼写的学习状态与词本关系独立。
7. 本轮错词重练保持原提示方式；不自动启动重练。阈值修改只影响后续判分，不批量重写历史。
8. CSV/XLSX 第一行列名约定 word, meaning, example, example_translation；同时接受常用中英文别名。重复拼写保留首次并在预览汇报；缺失英文/释义拒绝该行；无例句允许导入并标示缺失。导入创建新词库，不覆盖既有进度。旧 XLS 请另存为 XLSX/CSV。
9. 备份为版本化 JSON 完整学习档案；恢复采用覆盖，先确认、再自动生成现有档案副本。缓存可重新生成，不含在档案备份中。
10. 在线供应商尚未最终确认：先提供可替换 Azure 适配器，未配置时使用本地美音。不内置第三方账号或秘密密钥，不声称免费；需要用户已有服务凭据时可能产生供应商费用。
11. 内置词库采用本项目原创的六级备考精选词条、原创中文释义及例句，标明规模和边界，不声称覆盖官方完整大纲。避免未经验证地复制商业词典；后续可导入用户获授权的完整词库。

## 实施与验收顺序

1. 确认架构与边界，建立模型、原子存储与内置词库。
2. 实现单列背诵、逐级展开、排序位置恢复、熟词、默认收藏及自定义词本。
3. 实现最近/随机抽词、中文/听音默写、即时判分、结果与可选错词重练、错词历史与阈值。
4. 实现 XLSX/CSV 导入、语音适配与缓存、完整备份恢复、异常保护。
5. 测试核心流程与持久化、导入和备份边界；实机打开桌面程序验证界面；按 AT-01 至 AT-22 记录通过、条件通过或未验证。
6. 打包便携版、源码与重建脚本、使用说明、数据授权说明和测试报告。

无网页部署、手机端、打卡、排行、社交、云同步、变速或自动排课。
