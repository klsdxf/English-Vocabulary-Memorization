# V2.0 数据结构与变更

保留 V1.7 的 WPF 桌面程序、JSON 原子持久化、现有默写引擎、CSV/XLSX 导入及美式语音服务。在原代码中扩展 `Core.cs`、`Storage.cs`、`Program.cs`、`UI.cs`，新增 `Migration.cs`、`PaginationUI.cs` 与 `Animation.cs`。不引入在线账号、SQLite 替换、网页端或无关学习系统。

## 数据结构

`data/builtin.json` 为 Vocabulary 对象：Id 为原 `builtin-cet6-original-v1`；Edition 标记词书版本；Words 是固定原始序列。词条字段如下：

| 字段 | 含义 |
|---|---|
| Id | 稳定标识；旧匹配词沿用原 ID；新 ID 可处理跨库碰撞 |
| English / PartOfSpeech / UsIpa / Meaning | 英文、词性、美音、中文释义 |
| Examples[] | 英文句子与对应中文；每句独立朗读 |
| Senses[] | 词性、定义、可选义项美音、具明确证据的例句索引 |
| Formal | 正式收录标记；旧未匹配词为 false |
| OriginalIndex | 正式词的稳定原始位置；不由界面另排字母顺序 |
| Source / SourceKey / PronunciationSource | 词书、章节点和读音来源 |

SchemaVersion=2 新增 Reading 与 Migrations；保留 Notebooks、Progress、Errors、Sessions、Settings、ActiveSession、CurrentVocabulary、Positions。Reading 保存四套页容量、各模块页码与稳定词条锚点/页内逻辑位置；收藏页容量共享、各本位置独立。Progress.MasteredAt 仅在新熟词操作时写真实时间，旧时间未知为 0。Attempt.ResultKnown 标明可靠结果；不完整轮次保留 LegacyRecordJson，不修改原始作答为虚构答案。迁移记录保存真实存在的旧轮次 ID 集合 LegacySessionIds，使升级后新产生的可靠作答能够覆盖无时间的旧未知证据，旧答题时间仍保持原值。

## 行为与默认值

默认四类页容量均为 20，可选 10/20/30/50；底层支持 1–200，方便以后调整选项。非法页码留在原页并标识输入错误；超出当前结果范围的旧页码回落到最后有效页。用户跳页立即更新数据，220ms 动效不锁定按钮。

旧随机序列的其他词相对顺序不变，新词追加；熟词仅过滤隐藏，恢复后回到保存序列。旧学习锚点换算为所在页和页内位置。新增正式词按主体/补充词书的稳定顺序加入，原 301 个匹配旧词保持旧相对顺序，不进行全库字母重排。

已记诵 = 当前熟词 OR 最后可靠默写正确。未知/更晚不完整证据使默写来源不被推定有效；现有熟词仍有效。最近成功排序使用当前有效熟词时间或最后正确时间，无时间用原库次序后备。当前熟词和当前默写正确来源可单独筛选，全部不重复。

释义、例句、翻页、收藏、熟词移出、搜索侧板、页码导航、判分反馈均为 220ms 动效；收藏 110ms 往返，总计 220ms。输入、检索、逻辑翻页和音频调用即时进行；启动直接恢复，不播放翻页序列。自动朗读默认关闭且仍可单独开启。保存无弹窗；保存失败在底部说明，关闭时避免静默丢失。

## 已知限制

仅在本机 Windows 11/.NET Framework 4.8/SDK 9.0.101 环境实际验证；目标仍为 Windows 10/11、.NET Framework 4.7.2 以上，未在第二台 Windows 10 或干净虚拟机实测。无代码签名证书或安装器，交付可直接解压运行包。Azure 适配器、本地 HTTP 失败回退、缓存及真实 Windows 美音通过测试，未使用用户真实 Azure 凭据联网验证。

导入仍为原先的 CSV/XLSX；旧工程没有 Word 导入，文档中泛称 Word/CSV 不据此擅自添加 Word 解析。自定义词库缺失 IPA/例句译文时按原内容保留。词书内容质量规则的局限另见质量报告。
