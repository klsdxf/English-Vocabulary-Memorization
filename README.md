# 六级词汇 Windows V1.7 实现版

## 推送到 GitHub

首次连接仓库后，在本文件夹双击 `Push-to-GitHub.cmd`，即可检查待提交文件、提交修改并推送到 `klsdxf/English-Vocabulary-Memorization`。第一次使用时，Git 可能要求在浏览器登录 GitHub。脚本会拒绝推送到其他仓库；发现疑似密钥或私人学习数据时也会停止。GitHub 中会包含源码、原创词库和便携版主程序，忽略本地档案、语音密钥、备份及构建临时文件。

解压便携包后，双击 **六级词汇.exe** 即可使用。软件面向 Windows 10/11，使用 .NET Framework 4.7.2 或更高版本（通常由 Windows 预装），无需安装 Python、Node、Excel 或 .NET SDK，不需要账号或服务器。

本版实现单列背诵、逐级展开、固定/随机排序与位置恢复、熟词、默认收藏和多词本、中文/听音默写、错词复习、CSV/XLSX 导入、自动保存与完整备份。

**交付边界：**内置 348 个原创备考精选词条，每词包含中文释义和一条例句，不声称覆盖官方完整六级大纲。可导入自己的获授权词库。本地发音使用 Windows 美式英语语音；在线发音提供可替换的 Azure Speech 适配器，需要自己的服务区域和密钥，可能产生费用。没有配置在线服务时，本地功能仍可使用。

## 开始背诵

1. 第一次打开只显示英文；点击正文一次看中文，第二次看例句，第三次收起。
2. 点击“发音”或“朗读例句”独立播放。自动朗读默认关闭，可在“更多 → 设置与数据”开启。
3. “熟词”会立即移出待背列表；“更多 → 已掌握词汇”可恢复。
4. ☆/★ 一键加入或取消默认收藏。单词本页面可新建、重命名、删除自定义词本，选择单词后加入其他词本。Ctrl 可多选。
5. 可以切换固定/随机顺序。关闭重开会保留当前词库、排序及滚动位置。

## 默写与错词

“最近 X 个词”只取主动展开释义或例句的单词，按最近一次展开时间排列并去重；仅滚动、全局中文显示、发音和收藏不算主动学习。

“随机抽取”支持当前整个词库、已主动学习的词和指定单词本；题数可自定。范围不足时会询问是否按实际数量开始。临时默认包括已掌握词；各词库的同拼写词条保持独立状态。

开始前可选择中文或听音提示。输入英文后提交（也可按 Enter）。判分忽略大小写和首尾空白，不接受近似拼写、额外内部空格或词形替代；空输入不会提交。答错会立即显示正确拼写并写入独立错词记录，不自动收藏。

每轮结束可选择重新默写本轮错词或结束。未完成轮次保留在本机，再进入默写页可继续。默认连续答对 2 次移出待复习，阈值可调；再次答错时连续计数归零。“更多 → 错词记录”可移出/恢复，切换到全部历史错词后可查看已移出的记录。

## 导入自己的词库

入口为“更多 → 词库管理 → 导入 CSV / XLSX”。不需要安装 Excel。

第一行列名：`word,meaning,example,example_translation`。英文与中文释义必填，例句及例句翻译可选。同时支持“单词、释义、例句、例句翻译”等中文列名；CSV 支持 UTF-8（含 BOM）及 GB18030。XLSX 读取第一张工作表，旧 XLS 请另存为 XLSX/CSV。

导入前会预览有效词数、重复数、无效行和缺失例句数。重复拼写忽略大小写并保留第一条；缺失英文或释义的行跳过，缺失例句会明确显示。每次导入建立独立词库，不覆盖已有学习档案。文件最大 50 MB，全部词库最多合计 10 万词条。

`data/词库导入模板.csv` 可直接填写。`data/六级备考精选.csv` 是本版原创数据的可导入副本。

## 语音与在线配置

只支持美式英语、正常语速。在线成功后缓存音频；在线失败自动回退 Windows en-US 语音，并缓存本地音频。缓存命中可离线播放。系统缺少可用美音时会明确提示，可在 Windows 语言设置安装英语（美国）语音后再试。

若已有 Azure Speech 资源，在“更多 → 设置与数据”填入区域（例如 eastus）和服务密钥。留空密钥会保留现有密钥；清空区域停用在线服务。密钥由 Windows DPAPI 加密保存在当前 Windows 用户下，不写入学习备份。在线请求只发送本次要朗读的英文文本，不上传完整学习档案。在线服务的可用性和费用由供应商决定，软件未附带账号或免费额度。

实现依据：[Microsoft 官方文本转语音 REST 文档](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech)。本版固定 en-US-JennyNeural 与正常语速。

## 自动保存与完整备份

默认数据目录为 `%LOCALAPPDATA%\CET6Word`，移动或替换程序文件不会删除学习档案。设置页面会显示具体目录。程序只允许同一数据目录有一个实例写入；保存失败会在底部明确提示，关闭时提醒尚未保存的修改。

通过“设置与数据”导出 `.cet6backup` 完整备份，到另一台电脑使用“从备份恢复”。备份包含导入词库、排序及位置、学习记录、熟词、词本、默写轮次及作答、错词历史和偏好；不含可重新生成的语音缓存或在线密钥。新电脑需重新配置在线密钥。恢复会覆盖当前档案，验证格式和校验码后才写入，并自动保留恢复前副本。

主档案损坏时，程序会尝试恢复上一份安全副本并保留损坏原件；若副本也无法使用，启动时可选择完整备份恢复。安全副本是故障保护，建议自行定期导出完整备份用于跨设备迁移。

## 源码与验证

源码包包含独立的学习逻辑、存储、导入、语音和 WPF 界面，以及测试和构建脚本。重建需要 .NET SDK，运行 `build.ps1`；执行 `build.ps1 -Test` 可运行测试，输出到临时目录，也可用 `-TestOutput` 指定目录。运行程序本身不需要 SDK。

可使用 `六级词汇.exe --data-dir "指定目录"` 创建独立档案，便于测试或不同使用者隔离。

架构和全部临时默认值见 `docs/架构与开发计划.md`；逐项验收及验证边界见 `docs/验收报告.md`；数据来源与授权见 `docs/词库与授权说明.md`。源码及原创数据采用 MIT 许可，许可文本随包附带。
