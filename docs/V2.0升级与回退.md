# V2.0 升级与回退

V2.0 沿用原 C# / WPF / .NET Framework 4.7.2 软件与 JSON 本机档案。无需安装新数据库或创建账号。解压 Windows 包，先关闭旧软件，再双击包内的 `六级词汇.exe`；配置文件与程序保留在一起。

## 首次升级

默认档案仍位于 `%LOCALAPPDATA%\CET6Word`。程序读到 V1.7 档案后自动升级，在提交前保存 `before-v2-时间.cet6backup`，验证其校验码和可读性，再合并词库并核对个人记录。成功后档案为 SchemaVersion=2，保存内置迁移报告及独立的 `migration-v2-report.json`。重复启动不会重复加入收藏或答题记录。

301 个旧词匹配新版并保持旧 ID；47 个未匹配词继续保留，包括相关学习记录。正式词书为 2955 词，升级后原库共 3002 词（其中 47 个为旧档案保留项）。保留项仍可在待背、旧收藏及已记诵中使用；原词书和全库搜索展示正式词条。导入词库保留原 ID、内容与学习记录，不跨库合并同拼写词。

迁移先在内存完成，验证后采用临时文件写入、磁盘刷新和原子替换。提交失败时旧 `state.json` 保持有效，升级前备份也可使用；无效档案不会被静默重置。完整历史保留；不完整默写记录另保留原始轮次 JSON，缺失正确性或可靠时间时不推断记诵成功。不为旧熟词编造时间。

恢复 V1.7 完整备份到 V2.0 时，同样自动备份、合并。V2.0 完整备份包含新版词库及所有个人记录；密钥和可再生成的音频缓存继续留在本机，不随备份导出。

## 回退到 V1.7

1. 关闭六级词汇软件。
2. 双击 `回退到V1.7.cmd`。它验证最近的升级前备份，恢复其中的原始 V1.7 档案，并把当前 V2.0 档案保存为 `before-rollback-时间.json`。
3. 脚本启动包内 `rollback/V1.7/六级词汇.exe`。回退后使用此旧程序；再次启动主目录的 V2.0 程序会重新安全升级。

回退恢复的是升级时点的旧数据；升级以后新增的操作在 `before-rollback-时间.json` 中保留，不能由 V1.7 直接读取。要恢复升级后档案，先关闭软件、保存当前旧档案副本，再把该安全副本复制为数据目录的 `state.json`，使用 V2.0 启动。

指定档案/指定备份的高级用法：

```powershell
./tools/Restore-V1Backup.ps1 -DataDirectory 'C:\学习档案' -Backup 'C:\备份\before-v2-时间.cet6backup'
# 单独执行自动迁移，不打开学习窗口
Start-Process './六级词汇.exe' -ArgumentList '--data-dir "C:\学习档案" --migrate-only' -Wait
```

## 已验证的范围

真实旧档案使用工作区副本演练，原默认档案未修改。副本升级及回退校验通过，回退后的原始数据可由原 V1.7 解码器读取。真实档案没有学习/默写历史，因此另用包含收藏、多词本、熟词、学习、错词、完整/不完整作答、导入同拼写词、随机锚点的合成档案测试保全、幂等、冲突与失败回滚。见 `V2.0迁移核对结果.json` 与自动化测试记录。
