# 内置词库来源与授权

本版内置 **348 个六级备考精选词条**，英文、中文释义和一条英文例句均可在离线环境直接使用。词目围绕常见学术、科技、社会及考试阅读主题整理；本项目自行撰写中文释义与例句，使用 AI 辅助起草，没有复制第三方商业词典的释义、例句或音频。

这是一份备考精选集合，**不是官方完整六级大纲，不保证覆盖全部考试词汇或全部词义**。没有把未经核验来源和授权的网上“完整词库”直接打包。后续可用 CSV/XLSX 导入用户获授权的完整词库。

每个词条包含唯一标识、英文、中文释义和可扩展的例句列表。本版默认显示一条例句，例句翻译字段可留空。源数据见 `data/精选词库.tsv`，运行时数据见 `data/builtin.json`；程序内嵌相同数据，CSV 副本可独立导入。

词目去重、必填字段、例句包含目标词、JSON 可解析及运行时加载已自动检查。释义采用简明解释，不提供发音音标或权威词典认证。内置中文提示与例句完全来自本项目，不依赖网络查询。

源码和本项目原创数据统一使用随包附带的 MIT 许可，允许使用、修改和再分发，并要求保留许可文本。用户导入的其他词库不由本项目自动授予任何额外使用权。

本项目没有打包或再分发 Microsoft 语音库、Windows/.NET 运行时或 Azure 服务音频。Windows 本地语音由使用者自己的系统提供；在线服务由使用者配置自己的凭据。获取的音频仅供本机播放缓存，供应商服务使用及音频使用规则应遵循对应服务条款。
