# V2.0 增量实施清单与兼容性设计

依据用户提供的 2026-10-13 增量确认稿，在原 WPF 项目中迭代，保留既有界面与业务组件，不新建替代项目。当前仓库 README 的后续修改一并保留。

## 已核对的基线

现有代码使用 .NET Framework 4.7.2、WPF、版本 1 JSON 档案、原子文件替换与上一版本副本。单词标识在收藏、进度、错词、默写及位置中直接关联；旧随机序列包含完整词库，熟词通过过滤隐藏。逐题作答记录含答案、正确性和时间，因此现有完整记录可重建最后一次默写结果。旧版 348 个内置词标识为 builtin-英文。

源码及必要配置已保存到工作区升级前快照；真实默认档案已按原始字节备份并记录 SHA256、JSON 可读性与记录数。真实档案目前只有 1 词库、348 词、1 默认词本，无收藏/熟词/学习/默写/错词记录，不能宣称用它覆盖了有历史记录的迁移测试；后续另外建立含完整和不完整历史的脱敏测试副本。

## 实施顺序

1. 调研成熟六级主体词表及内容数据许可，固定来源版本和文件哈希。生成六项字段结构、检查脚本、异常修复/排除记录。目标 2800–3200 正式词条，未核实异常不得用占位文本补齐。
2. 扩展现有数据模型，版本 2 与版本 1 共用兼容读取路径；新增词性、美式 IPA、义项、来源和原始序号。保留旧词标识，可靠同拼写仅在原内置词库内匹配；自定义词库绝不合并。
3. 在档案副本上合并新词书，迁移前验证完整备份；内存中完成关联与记录数审计后原子写入。记录迁移版本，使重复运行幂等。未匹配旧词原样保留并标为旧档案保留项，不凑正式词数。
4. 背诵分页：20 默认、10/20/30/50 可选，按稳定锚点恢复分页及页内位置；键盘输入时不截获左右键；熟词立即补位，恢复时不重排随机队列。
5. 添加全内置正式词书的英文只读搜索侧板，保留背诵内容，不写任何学习状态。
6. 单词本重构为原词书、收藏词本、已记诵词本三个入口；各模块独立分页，收藏共用页容量但每本单独位置。
7. 已记诵严格按当前熟词或最新可靠默写正确判定；缺失历史不猜测、旧标记缺失时间不伪造时间。独立于错词连续正确阈值。
8. 沿用现有 WPF 控件加入轻盈视觉与八类 180–300ms 动效，逻辑更新、输入、语音、搜索、保存、启动恢复不等待动画完成。
9. 运行 V1.7 回归及 V2.0 AT-01–31，渲染并检查新页面，独立包启动与源码重建，交付迁移/回滚、质量、验收和变更报告。

## 风险和工程处理

- 新内容不能改变旧作答的判分证据：匹配词保持标识及英文，内容可升级，历史原样保存。
- 旧记录缺少最后答题证据时仅由熟词标记认定已记诵，不从连续次数/参与次数推断正确。
- 迁移先生成独立 V1.7 可恢复备份，不把原子写入的上一版本副本当作唯一回滚材料；新版本恢复旧备份后会重新安全迁移。
- 旧位置使用词条锚点转换，不能把旧整数页码直接沿用；随机旧词相对顺序保留，新词稳定追加。
- 公开仓库的代码许可不自动证明抓取的商业词典内容可再分发。词表、释义、IPA 和例句分别核实来源许可，记录残余风险。
- 自定义导入词库继续允许没有 IPA/例句翻译，不补造、不删除；六项强制校验只适用于新版正式内置词书。
- 正式词书以来源稳定顺序为准；原始顺序不是由界面强制字母排序。

## 完成门槛

正式词数和内容质量、迁移完整性与幂等、分页/搜索/词本/动态状态、八类动效及六条禁区均需有实际验证记录。未完成或未执行项如实标注，不因界面已可运行而提前宣告全部升级完成。
