## 可靠性与修复

- 存储使用写临时文件、刷盘、原子替换与上一版本副本。主档损坏能恢复有效副本并保留损坏原件；无法恢复时不会悄悄清空数据。
- 备份验证版本、校验码及词条/词本/进度/默写关联；篡改、未知版本和非法关联会在写入前拒绝。
- 同一数据目录的文件锁防止两个实例同时写入。保存失败显示未保存提示；关闭时提醒。
- CSV 引号错误、缺失必要列、全无效数据行、重复词和缺失例句已有检查；XLSX 禁止外部 XML 实体，限制解压大小。
- 语音密钥加密往返检查通过，完整备份中不包含密钥明文。
- 实机点击曾发现 WPF 模板内部事件未传到窗口，已改用原始事件来源并覆盖该集成路径。
- 列表重建不再二次覆盖已更新的锚点，中途熟词移出及词库切换已加入实际界面回归检查。
- 受限执行环境无法加载 Windows 语音引擎；在正常桌面环境复核成功。这属于测试环境限制，不作为软件语音失败处理。
- 背诵、展开、中文默写、听音默写和设置页面已实际渲染并检查，未发现遮挡或文本裁切。

## 已说明的边界

内置数据为 348 词的原创精选，不是经官方核验的完整考试大纲。在线供应商采用暂定可替换适配器，真实云端连接需要使用者自己的有效区域与密钥；本次测试不声称验证了其账号、地区或收费条件。源码保留供应商替换接口。

CSV/XLSX 支持约定列名，不提供复杂交互列映射；旧 XLS 需要另存。恢复采用覆盖并生成副本，尚未实现合并；这是已记录的工程默认值。语音缓存可重建，不属于迁移所需的关键学习档案。

所有未确认细节及暂定策略见《架构与开发计划》，没有将它们标成用户已确认。未添加网页、手机端、账号、云同步、打卡、排行、社交、变速或自动排课。
