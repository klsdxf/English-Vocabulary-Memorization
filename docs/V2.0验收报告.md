## 实际环境与未验证项

本机 Windows 11、.NET Framework 4.8、.NET SDK 9.0.101；本地实际美音为 Microsoft Zira Desktop/en-US，生成有效 WAV。在线适配器对本地 HTTP 服务验证请求、鉴权字段、US 声音、SSML、缓存、401 回退；未调用真实 Azure 账号。没有在第二台电脑或 Windows 10 干净系统安装验收；这些兼容性范围标为未验证，不由本机成功推定。

词库内容的自动规则有语言准确性局限，详见质量报告；未把全量结构通过等同于 2955 词逐条人工正确性担保。最终包解压、二进制版本、无窗口 新建/升级、源码重建和排除档案/密钥的打包审计另记录在交付验证记录中。
